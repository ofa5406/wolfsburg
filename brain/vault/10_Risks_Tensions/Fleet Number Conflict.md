# Fleet Number Conflict

An honest inconsistency the brain refuses to average away: the project carries **two fleet totals**. The locked decision and all narrative documents say **763 vehicles** ([[Fleet Sizing Formula Accepted]], [[Fleet]]); the web tool's Data mode computes **1,273** from its own formula (peak trips ÷ capacity × duration + reserve) ([[Wolfsburg Activity Map]]).

The divergence is methodological, not arithmetic error: different assumptions about peak load, occupancy and reserve factors produce different totals — which is precisely the lesson of the methodology gap: a static formula's output moves with its inputs, and only an agent-based run would arbitrate ([[Methodology vs Code Gap]], [[VW Shift Wave Simulation]]).

Until reconciled, the project's exposure is a juror comparing the deck to the live tool. The register's rule applies: name it first. The tension is recorded here with `contradicts` edges in both directions, the decision documents lead with 763 as the locked figure, and the tool's number is presented as a scenario output, not a second truth ([[Risk — Fleet Math Challenged]], [[Capacity Analysis]]).
