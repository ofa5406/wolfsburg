# Project Name Decision

Locked June 25, 2026: the project's official name is **`<stadt.hub>`**, replacing the working title "Auto-Stadt"; "Post-Car Future of Wolfsburg" and "Parking City → Hub City" remain the descriptive subtitle and thesis line.

The name compresses the project into six characters and a point: *Stadt* (city) joined to *hub* by the syntax of a domain or a code namespace — the city refactored, addressable, versioned. The angle brackets are deliberate typographic identity (and a practical footnote: in Markdown a bare `<stadt.hub>` parses as an HTML tag and vanishes, so it is always written in code style) ([[System Identity]]).

Dropping "Auto-Stadt" mattered strategically: the old title led with the car and read as a pun on Autostadt, VW's own visitor attraction next to the plant. The new name leads with the project's actual protagonist — the hub as the city's organising element ([[Hub City]], [[Mobility Hub]]) — and gives the exhibition identity its wordmark, blinking caret included ([[From Parking City to Hub City]]).
