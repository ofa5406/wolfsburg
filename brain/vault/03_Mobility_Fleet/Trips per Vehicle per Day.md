# Trips per Vehicle per Day

The decisive fleet metric: 100,000 trips ÷ 763 vehicles = **~131 trips per vehicle per day fleet-average** — a number that sounds absurd until it is decomposed by mode, which is exactly what the proof does. E-bikes deliver 6–10 rentals; shared EVs 4–8 longer bookings; micro-pods 25–40 short hops (~12,000 trips from that class alone); shuttle pods 60–90 pooled passenger-trips; buses 100–200 boardings.

The read-out: **the modal split carries the total, not a flat average.** Big low-cycle vehicles deliver throughput per trip; small high-cycle vehicles deliver trip count. The fleet is never asked to run 131 solo taxi rides per car. The per-mode figures are labelled as defensible reference ranges from real systems, not measured Wolfsburg values — an honesty flag the research file states explicitly.
