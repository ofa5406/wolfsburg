# Outdoor Fitness Element

A simple bar or balance element serving all ages, at M and L hubs — minimal by specification, because the palette wants a gesture toward movement, not an outdoor gym. The element rounds out the hub's health offer: the network already embeds physical activity in daily travel ([[Active Travel]]), and the fitness element extends that to the minutes around it — the stretch while waiting, the pull-up on the way past, the older user's balance practice.

Like the game table it is a licence for lingering with a purpose, and its all-ages framing matters: a single bar used by teenagers, commuters and seniors at different hours demonstrates the multi-clock hub better than any diagram.
