# Community Information Board

The physical noticeboard for local events and neighbourhood information, in [[Zone 3 — Dwelling Edge]] — standard at S-hubs, expected everywhere above. Deliberately analogue beside the digital [[Real-time Info Terminal]]: the terminal serves the system's information, the board serves the neighbourhood's — the choir concert, the lost cat, the flat exchange.

Its inclusion states whose place the hub is. A noticeboard only works where people pass daily and pause briefly, which is exactly the traffic a hub generates; in return it gives the hub a civic function that predates and outlasts any mobility technology. The board is the cheapest element in the palette and arguably the clearest test of [[Catalyst Not Shelter]]: infrastructure that hosts community notices has admitted it is a public place.
