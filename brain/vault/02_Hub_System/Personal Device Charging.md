# Personal Device Charging

USB and wireless charging embedded in benches or the canopy, applied at high-dwell locations. A small courtesy with system logic behind it: the entire mobility service lives on the user's phone — booking, unlocking, wayfinding — so a dead battery strands a user more completely than a missed bus. Charging at the hub is redundancy for the system's own interface.

The element also extends dwell time deliberately: someone charging a phone stays ten minutes, watches the street, buys a coffee at the kiosk — micro-loitering that feeds the hub's public life. Embedding it in existing furniture follows the palette's integration rule ([[Charging Point]] logic at personal scale): no freestanding charging totems, just benches that happen to be generous.
