# Memory History Marker

A marker at significant transformation sites — especially L-hubs on former car parks — telling **the Wolfsburg transformation story in place**. The element treats the post-car shift as heritage in the making: this building stored two thousand cars; this square was asphalt; this is what the city decided in the 2020s and why.

Memory markers guard against the amnesia that makes urban change reversible — a generation that never saw the parking crater will defend the square better if the square remembers. In Wolfsburg the marker also handles the city's identity with respect rather than erasure: the car century is narrated, not shamed, which is the project's whole diplomatic posture toward its host city compressed into one plaque ([[German Car Culture]]).
