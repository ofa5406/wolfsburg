# Toolpalette Category — Mobility

The palette's functional core: the elements where vehicles and people actually meet. It contains the [[E-bike Docking Rack]], [[Private Bike Parking]], [[Cargo Bike Dock]], [[Micro-Pod Zone]], [[Shared EV Bay]], [[AV Drop-off and Pickup Zone]], [[Charging Point]], [[Real-time Info Terminal]] and [[Public Transport Shed]].

Mobility elements concentrate in [[Zone 1 — Vehicle Edge]] and scale with tier: an S-hub carries only the light end (e-bike dock, micro-pod zone), while M and L add the car-sized and bus-sized infrastructure. The category's design discipline is integration — charging lives inside docking furniture, the PT shed can merge with the canopy — so that the machine layer never overwhelms the place. In the hub-viewer's category legend this family renders in muted blue.
