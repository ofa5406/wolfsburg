# Hub Toolpalette

The complete element catalogue from which every hub is composed — the [[Kit-of-Parts]] made explicit. Roughly 45 elements are organised in nine categories: [[Toolpalette Category — Mobility]], [[Toolpalette Category — Wayfinding and Accessibility]], [[Toolpalette Category — Shelter and Comfort]], [[Toolpalette Category — Environment]], [[Toolpalette Category — Social and Cultural]], [[Toolpalette Category — Lighting]], [[Toolpalette Category — Street and Crossing]], [[Toolpalette Category — Optional Elements]], and the L-tier-specific set under [[Toolpalette Category — Typology Specific]].

Elements split into **essential** (the core kit, with per-tier mandatory/standard grades) and **optional** (context-specific, applied where location and programme warrant). The palette exists in three synchronised forms: the design document, the Rhino block library of 45 modelled elements on material-based layers ([[Rhino Toolpalette Kit]]), and the interactive [[Hub Viewer]] where each element carries a description card. One catalogue, running from concept to geometry to exhibit.
