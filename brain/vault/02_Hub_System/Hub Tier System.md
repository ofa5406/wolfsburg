# Hub Tier System

The three-level hierarchy that lets 68 hubs behave as one network. Each tier is defined by **urban role** first and equipment second: the [[S-Hub]] is "the moment" (last-mile, 150–250 m walk), the [[M-Hub]] is "the choice point" (multimodal transfer, 300–500 m), the [[L-Hub]] is "the neighbourhood anchor" (full fleet plus programme, 700–1000 m). Smaller catchments tile the gaps between larger ones, so coverage is cumulative rather than duplicated.

Tiering is standard practice in hub planning — CoMoUK's typology and the Bremen/Bergen/Minneapolis programmes all grade their hubs — but the project's twist is that tier membership drives the element palette mechanically: each toolpalette element carries a per-tier requirement (mandatory, standard, optional, absent), so a tier is effectively a *bill of materials* plus a role description.
