# Material — Context

The kit's background layer: surrounding buildings, existing street surfaces, kerbs and the ambient city that every sample hub scene sits inside. Context is modelled as its own material family so the palette elements always appear *in situ* — the S, M and L sample scenes in the Rhino file and the [[Hub Viewer]] render context in muted greys, letting the hub's red field and coloured elements carry the figure against a quiet ground. The layer embodies a design rule: hubs are judged in their street, never as isolated objects.
