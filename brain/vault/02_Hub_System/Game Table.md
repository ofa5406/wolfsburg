# Game Table

A chess or ping-pong table at M and L hubs with generous outdoor space and social ambition. The game table is a public-life classic with an evidence base any element would envy: from New York's chess tables to Berlin's park ping-pong, a fixed game surface reliably produces recurring, intergenerational, stranger-mixing use — the exact social alchemy the [[Catalyst Not Shelter]] principle orders.

Games also solve the loitering paradox: societies suspicious of people "hanging around" happily accept people *playing*, so the table licenses presence. At an L-Anchor's open space, the cluster of game tables, [[Group Seating]] and the kiosk sketches the hub's afternoon identity — the mobility system's contribution to the neighbourhood's living room.
