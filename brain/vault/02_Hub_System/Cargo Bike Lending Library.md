# Cargo Bike Lending Library

A lending point for cargo bikes where demand runs high — complementary to the regular [[Cargo Bike Dock]], offering longer borrowing periods for the moving day, the allotment weekend, the market stall. The "library" framing is exact: reservation, checkout, return, and a shared asset whose idle time is redistributed as neighbourhood capacity.

German cities already run such libraries successfully (the *freie Lastenräder* commons movement), so the element imports a proven civic institution rather than inventing one. At hubs it inherits the infrastructure it needs — charging, shelter, visibility, foot traffic — and in return it covers the trip profile that most stubbornly justifies household car ownership: bulky, occasional, unplannable cargo.
