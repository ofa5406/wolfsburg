# Parcel Pickup Lockers

Delivery lockers at hubs where last-mile parcel volume is high — the element that folds e-commerce logistics into the mobility network. Consolidating deliveries to locker banks removes the door-to-door van circuit from the filtered zones: one cargo-bike run fills fifty lockers that fifty separate van stops would otherwise serve.

For the user the locker rides the commute: collect the parcel where you collect the e-bike. For the system it makes the hub a freight node as well as a passenger one, which the [[Freight and Emergency Access]] planning requires the zones to handle honestly. The locker is quiet proof that the post-car city has an answer for the delivery economy that grew up inside the car city.
