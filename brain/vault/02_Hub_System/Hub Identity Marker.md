# Hub Identity Marker

The panel or integrated element carrying the hub's name, its tier (S, M or L), and a map of nearby hubs — mandatory at every tier, standing in [[Zone 2 — Threshold]]. It is the network's node label made physical: the one element whose entire job is to say *you are here, this is what here is, and there is a system*.

The nearby-hubs map does quiet network pedagogy — it teaches users that the hub is not an isolated amenity but a mesh, and that a fuller-service M-hub is a few hundred metres away. Precedent: Bremen's mobil.punkt pillar, whose consistent roadside totem made a scattered car-sharing network legible as public infrastructure ([[Bremen mobil.punkt]]).
