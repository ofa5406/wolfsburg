# Exhibition Deck

The Summaery centrepiece: `exhibition/deck/` — a vertical full-page deck (one scroll, one page) in the project's exhibition identity: near-monochrome, thick L-frames, the `<stadt.hub>` wordmark with its always-blinking caret, and **every line of prose typed live** by a typewriter effect, occasionally mistyping and correcting itself ([[System Identity]], [[Project Name Decision]]).

Its defining decision: the maps are **the real components, embedded offline** — the Activity Map's sections build into the deck via a dedicated embed bundle, with their own working tab controls, rather than appearing as screenshots ([[Wolfsburg Activity Map]]). The 3D hub slide embeds the [[Hub Viewer]] in kiosk mode; a **Present** button auto-plays the loop for unattended running, pausing embedded render loops off-screen; the persona cycle carries Thomas, Sabine, Lukas and Gertrude ([[Thomas]], [[Summaery Exhibition]]).

It superseded the earlier single-screen kiosk build (whose question-led beats and camera-tour bridge it absorbed), and it is the host into which the project brain's 3D graph docks as a slide ([[Project Brain]]).
