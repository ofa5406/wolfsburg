# Project Brain

The artifact you are inside: the `<stadt.hub>` project atomised into a **knowledge graph of ~500 linked notes** — every concept, element, finding, precedent, decision, persona, place, tool, risk and deep-dive, each a markdown note with typed connections, compiled into the 3D force-directed viewer on the exhibition kiosk ([[Summaery Exhibition]], [[Exhibition Deck]]).

The brain has two lives. As **working memory**, it is an Obsidian-compatible vault: the team opens `brain/vault/` and navigates the project by wikilink, with a validator enforcing zero broken links and zero orphans ([[Session Memory System]]). As **exhibit**, it renders the project's *reasoning* the way the drawings render its spaces — visitors orbit the graph, follow edges from a hero number to the decision it justified, and read any node in a detail panel ([[System Identity]]).

Its epistemic rules are the project's own: claims carry sources and confidence; contested numbers keep their caveats; contradictions are edges, not embarrassments ([[Fleet Number Conflict]], [[Proof Framework]]). The graph *is* the argument, navigable.
