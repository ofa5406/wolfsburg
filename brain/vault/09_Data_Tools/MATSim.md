# MATSim

The open-source, agent-based transport simulation framework — the scientific engine of professional mobility planning, and the engine under MOIA's MIA platform ([[MIA Mobility Impact Analyzer]]). In MATSim every traveller is an agent with a daily plan; agents route, learn and re-plan across iterations until the system reaches a behavioural equilibrium — simulation, as against the division formulas of first-order estimates.

For the project MATSim marks the **methodological horizon**: the named upgrade path from the current static fleet math to a defensible simulated number ([[Methodology vs Code Gap]], [[VW Shift Wave Simulation]]). The realistic scope is one scenario — the shift wave — in MATSim or the lighter, purpose-built FleetPy (TU München's open ridepooling simulator); a full model is out of range before the deadlines and is honestly labelled roadmap, not deliverable.

Citing it already does rhetorical work: MOIA's public MATSim showcase means the project's fleet claims can lean on the same engine's published results — the AMAG/Zurich study above all — while the team's own run remains pending ([[Fleet Sizing]], [[Capacity Analysis]]).
