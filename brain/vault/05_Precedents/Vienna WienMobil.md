# Vienna WienMobil

The clearest running demonstration of **baseline-element-plus-add-ons** — the compositional rule the Hub City's toolpalette runs on. Vienna's WienMobil Stationen, rolling out since 2018 under the transit operator Wiener Linien, hold one element constant at every station — **WienMobil Rad bike-share** — and layer capability by site: e-car-share, e-scooters, bike service stations, bike and parcel boxes ([[Hub Component Ladder]]).

The operator-brand model matters as much as the element logic: one recognisable identity across many physical stations makes the network legible as *one system* rather than scattered amenities — Munich's MVG *more* applies the same principle ([[Munich MVG more]]). This is the argument for Wolfsburg's single design language across 68 hubs: shared beacon, shared paving, shared pictograms, so the S-hub two blocks away is recognisably the same infrastructure as the L-hub at the station ([[System Identity]], [[Hub Toolpalette]]).

Vienna also anchors the tier escalation empirically: bike-share everywhere, decision infrastructure where footfall justifies it — Wolfsburg's S→M→L ladder with a transit operator's fifteen-year track record.
