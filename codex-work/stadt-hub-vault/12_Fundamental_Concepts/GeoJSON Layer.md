# GeoJSON Layer

## Definition

A spatial data file containing map features such as roads, parking, parks, transit, or facilities.

## Why It Matters Here

Most Activity Map analyses are built from GeoJSON layers.

## Do Not Confuse With

A data layer is not yet an insight. It needs method, interpretation, and design response.
