# Hub System Concept Versus Tool

Three models of the hub system coexist: design concept, implemented web-tool code, and public methodology text. The June 17 decision resolves the design concept but leaves implementation gaps.

## Key Resolution

Separate where a hub is placed from what a hub is. Parking infrastructure can support location/service logic, while the surface hub remains a public place.

## Open Implementation Gaps

- L-Gateways counting toward the six L-hub total.
- Central L-Anchor placement while code excludes some central districts.
- Walking catchments versus service radii.
- Public methodology page versus actual algorithms.
